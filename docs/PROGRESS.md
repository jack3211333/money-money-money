# 目前進度

## 已完成

- Vite + React + TypeScript 深色手機優先 PWA、可安裝 manifest 與離線 app shell。
- Supabase migration：完整資料表、時間欄位、軟刪除、更新時間 trigger、RLS。
- 資料存取層、Email＋密碼登入／登出，以及已登入帳號設定密碼。
- 帳戶／分類、收支／轉帳、負債／分期、股票、總覽、CSV 匯出、12 個月推演頁。
- 已通過 `npm run build` 正式建置檢查。
- Vercel 部署網站目前可正常開啟；PWA 快取修正已推送至 GitHub，Vercel 會自動部署。
- 已確認關閉本機網址與終端機不會影響 Vercel 或 Supabase 雲端資料。

## 已知問題

- 若目前所有裝置都已登出，需等寄信額度恢復，或設定自訂 SMTP，先用一次性登入連結恢復帳號，再設定密碼。
- Email OTP 與魔法連結都會寄信，不能用 OTP 避開內建寄信額度。
