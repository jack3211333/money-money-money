# 重要決定

| 日期 | 決定 | 原因 |
| --- | --- | --- |
| 2026-10-23 | 使用 Vite + React + TypeScript + PWA | 輕量、適合響應式網頁與安裝至手機主畫面。 |
| 2026-10-23 | 使用 Supabase Auth/Postgres + RLS | 提供雲端同步、Email 登入與依使用者隔離的資料安全。 |
| 2026-10-23 | 採 Email 魔法連結登入 | MVP 不需自行處理密碼與重設流程。 |
| 2026-10-23 | 使用 TWD 整數元儲存金額 | 避免浮點誤差，符合日常記帳。 |
| 2026-10-23 | 所有刪除採軟刪除 | 保留歷史資料並降低誤刪風險。 |
| 2026-10-23 | 不支援人際借貸 | MVP 僅管理金融負債：貸款與分期。 |
| 2026-10-23 | 使用 GitHub + Vercel 部署 | Git 推送後可自動部署，電腦關機也可使用。 |
| 2026-10-23 | PWA 使用原生 manifest + service worker | 套件版本在此環境發布內容不完整；原生標準可保有安裝與離線 app shell，且減少依賴。 |
| 2026-10-23 | 推演不建立真實交易 | 使用者可安全測試固定收支、負債與持續投入，不會影響帳本。 |
| 2026-10-23 | 股票以成本或最後手動市值修正作為估值基準 | MVP 不串即時報價，仍可用手動年化報酬率推演。 |
